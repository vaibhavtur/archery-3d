# 3D Archery (React + three.js)

    npm install
    npm run dev      # open the printed localhost URL

- Move mouse to aim; click / tap / Space to shoot (5 arrows).
- Rings score 0, 5, 10, 15, 20 (bullseye). Restart button resets the game.
- Tweak TOTAL_ARROWS, STEP (ring size) and sway in src/game.js.
- `archery-standalone.html` runs directly in a browser, no install.
